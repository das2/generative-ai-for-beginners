## Creación de entorno

- Tener instalado Docker y su servicio en ejecución.
- Tener una [API KEY de la API de OpenAI](https://platform.openai.com/api-keys).
- Abrir carpeta raiz del repositorio con Visual Code.
- Crear archivo `.env` como copia del archivo `.env.copy`.
- Cargar vs.code-profile (si no está instalado instalar el modulo ["Dev Containers"](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers) el profile debería incluirlo).
- Si al cargar el vs.code-profile no se intenta auto generar el DevContainer se puede invocar desde "Abrir una ventana rmeota" > "Open Contanier Configuration "File".
